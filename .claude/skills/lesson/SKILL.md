# 指摘を教訓として記録する

発表者の指摘を、次のデッキでも同じことを言われないための教訓にする。スライドを直す作業とは別に、直したあとで行う。

## 手順

1. **指摘を特定する**：引数があればそれを、なければ直前の発表者の発言を対象にする。発表者の言葉をそのまま短く引用する。
2. **残すかを決める**：次のどれかに当たるものだけ残す。当たらなければ「このデッキだけの好みなので記録しない」と一言伝えて終わる。
   - ほかのテーマのデッキでも起こりうる（書き方・構成・図の作り方・進め方）
   - 自分（エージェント）の進め方の誤りで、また繰り返しそう
3. **重複を確かめる**：`LESSONS.md` に同じ趣旨の教訓があれば、新しく足さずにその項目の「指摘」に今回の分を追記し、末尾に「（2回目）」などと回数を書く。2回目になったら、手順 5 で `CLAUDE.md` に格上げする。
4. **書き足す**：`LESSONS.md` の末尾に、次の形で1件足す。ID は最後の番号 + 1。
   ```markdown
   ### L0NN 〈ルールを短い1文で〉
   - 日付・デッキ：YYYY-MM-DD ・ 〈デッキの題〉
   - 指摘：〈発表者の言葉の要約〉
   - ルール：〈次から何をどうするか。具体的に〉
   - 反映先：未反映
   ```
5. **反映する**（できるものだけ）
   - 既存のルールの言い足しで済むなら、`CLAUDE.md` の該当する節に1行足し、「反映先」に書く。
   - 正規表現などで機械的に見つけられるなら、`rules/check-rules.json` の `patterns` に同じ ID で足し、`npm run check` を実行して、いまの `slides.md` で誤検出が出ないことを確かめる。
   - 反映しなかったものは「未反映」のまま残す（`/retro` でまとめて整理する）。
6. **報告する**：記録した ID とルールを1〜2行で伝える。
